## 1. 产品概述与定位

### 1.1 一句话定位

> 一款**超轻量、纯离线、零权限**的手机端 Markdown 阅读与轻编辑工具——阅读优先，需要改字时可随时进入源码编辑，不联网、不追踪、不收集任何数据。

### 1.2 核心原则（不可妥协的产品红线）

| 原则 | 具体约束 |
| --- | --- |
| **纯离线** | 不声明 `INTERNET` 权限；应用无任何网络请求代码路径 |
| **零权限** | 除「读取共享存储文档」（Android 13+ 走系统 SAF 文件选择器，无需权限）外，不申请任何系统权限 |
| **零追踪** | 无统计分析 SDK、无广告 SDK、无崩溃上报（或仅提供用户手动导出的本地日志） |
| **超轻量** | 安装包 ≤ 8 MB，冷启动 ≤ 500 ms |
| **阅读优先，轻编辑可选** | 阅读主链路不被编辑打扰；编辑只做源码级轻量能力，不做富文本/WYSIWYG、云同步、账号体系 |

### 1.3 差异化价值主张

现有 Markdown 工具普遍「重编辑、轻阅读」，且伴随权限膨胀与隐私顾虑。墨阅反其道而行：

1. **隐私可验证**：零权限 + 无网络权限，隐私承诺可由系统层直接验证，不依赖用户信任；
2. **极致轻量**：体积与启动速度对标系统自带文本查看器；
3. **阅读体验优先**：大纲导航、主题切换、代码高亮围绕「长文档阅读」场景深度打磨；
4. **本地轻编辑**：在同一个零权限、纯离线应用内完成 Markdown 源码修改、预览与保存，不把文档交给第三方编辑器。

## 2. 市场同类产品对比分析

### 2.1 主要竞品对比

| 产品 | 平台 | 体积(约) | 核心功能 | 优点 | 缺点 | 权限/隐私 |
| --- | --- | --- | --- | --- | --- | --- |
| **Markor** | Android | ~10 MB | 编辑+预览、TODO、离线 | 开源免费、功能全、纯离线 | 编辑导向，阅读排版一般；大纲导航弱 | 良好（开源可审计），但含编辑器等冗余功能 |
| **Obsidian Mobile** | Android/iOS | ~80 MB | 双链笔记库、插件生态 | 功能强大、生态成熟 | 体积大、启动慢；面向知识管理而非单文档阅读 | 闭源，含账号体系，权限较多 |
| **iA Writer** | iOS/Android | ~50 MB | 写作、聚焦模式 | 排版优雅、写作体验顶级 | 付费（iOS 约 ¥198）；写作工具非阅读器 | 良好但闭源 |
| **JotterPad** | Android/iOS | ~40 MB | 写作、云同步 | 界面美观 | 云同步/账号为卖点，离线纯阅读被边缘化 | 需网络与存储权限 |
| **Epsilon Notes** | Android | ~15 MB | 编辑、数学公式、图库 | 功能丰富（LaTeX、图表） | 界面老旧；功能臃肿 | 权限较多 |
| **Typora（移动端缺失）** | 桌面 | — | 所见即所得 | 桌面标杆 | 无官方移动端，移动阅读需求空缺 | — |
| **各文件管理器内置查看器** | Android/iOS | — | 纯文本/简单渲染 | 系统自带、无需安装 | 几乎不渲染 Markdown，无大纲、无主题 | 良好 |

### 2.2 竞品共性问题

1. **阅读是附属品**：几乎所有竞品以「编辑/写作」为核心，阅读体验（大纲跳转、夜间阅读、字号排版）投入不足；
2. **功能膨胀**：云同步、账号、插件市场带来体积与权限膨胀，与「快速打开看一眼文档」的轻量需求错配；
3. **隐私黑盒**：闭源 + 网络权限 + 统计 SDK，隐私承诺不可验证；
4. **大纲导航普遍缺失或难用**：长文档（技术文档、README、电子书式 md）阅读效率低。

### 2.3 差异化机会点

| 机会点 | 墨阅的打法 |
| --- | --- |
| 阅读体验赛道空白 | 阅读优先，把「打开速度 + 排版 + 大纲导航 + 夜间阅读」做到极致；编辑只做成不打扰阅读的次级能力 |
| 隐私焦虑用户增长 | 以「系统级可验证的零权限」作为核心卖点，上架描述即可列出权限清单 = 空 |
| 长 md 文档场景 | 自动生成大纲目录 + 点击跳转 + 阅读进度记忆，对标电子书阅读器体验 |
| 超轻量需求（低端机/存储紧张） | 安装包 ≤ 8 MB，冷启动 ≤ 500 ms，显著低于所有竞品 |

## 3. 目标用户画像与典型使用场景

### 3.1 用户画像

**画像 A：开发者 / 技术从业者（核心人群，约 50%）**
- 25–40 岁，手机中存有大量技术文档、README、API 文档、博客存档（md 格式）；
- 诉求：代码高亮正确、大纲跳转快、夜间模式护眼、不联网不泄敏（公司文档不敢传给带网络权限的 App）。

**画像 B：隐私敏感型用户（约 25%）**
- 对权限弹窗零容忍，偏好 F-Droid 开源工具；
- 诉求：可验证的零权限、无追踪、无广告。

**画像 C：文字工作者 / 学生（约 25%）**
- 用 md 写稿、存课程笔记、读 md 电子书/讲义；
- 诉求：排版舒适、日间/夜间切换、长文大纲导航。

### 3.2 典型使用场景

| # | 场景 | 关键路径 |
| --- | --- | --- |
| S1 | 微信/邮件收到 `.md` 附件，点击「用其他应用打开」→ 墨阅秒开渲染 | 系统分享 → 渲染阅读 |
| S2 | 地铁通勤（无网）阅读一份 200 节的技术手册，靠大纲跳着看 | 打开文档 → 大纲 → 跳转章节 |
| S3 | 睡前躺床上看 md 小说/笔记，切夜间模式 | 阅读中 → 一键切夜间 |
| S4 | 公司内网导出的敏感文档，必须用不联网的工具看 | 文件选择器 → 阅读（隐私安心） |
| S5 | 低端备用机存储紧张，需要小体积阅读器 | 安装（<8MB）→ 日常使用 |

## 4. 产品功能清单及优先级

优先级定义：**P0** = v1.0 必须有（核心闭环）；**P1** = v1.1–v1.2（体验增强）；**P2** = v1.3+（锦上添花）。

### 4.1 功能清单

| ID | 功能模块 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| F-01 | Markdown 渲染 | 标题、段落、列表、表格、引用、分割线、图片（本地相对路径）、行内/块级代码、链接（点击弹提示，不联网故仅可复制） | **P0** |
| F-02 | 代码语法高亮 | 内置高亮引擎，覆盖常见语言（js/ts/py/java/go/rust/c/c++/shell/json/yaml/html/css/sql 等 ≥ 20 种） | **P0** |
| F-03 | 大纲目录 | 解析 H1–H6 自动生成树状大纲；侧滑抽屉展示；点击跳转至对应章节并高亮定位 | **P0** |
| F-04 | 主题切换 | 日间/夜间双主题；支持「手动切换 / 跟随系统」两种模式；阅读页一键切换按钮 | **P0** |
| F-05 | 文件打开 | 系统文件选择器（SAF）打开；支持「分享/打开方式」接收外部 md 文件；最近文件列表（本地存储） | **P0** |
| F-06 | 阅读排版调节 | 字号 5 档、行距 3 档调节 | P1 |
| F-07 | 阅读进度记忆 | 记住每个文档上次阅读位置，再次打开自动定位 | P1 |
| F-08 | 文内搜索 | 关键词搜索、结果高亮、上/下跳转 | P1 |
| F-09 | 大文档优化 | >1 MB 文档分段渲染/虚拟滚动，滚动不卡顿 | P1 |
| F-10 | 编码识别 | UTF-8 默认，自动检测 GBK 等常见编码 | P1 |
| F-11 | 导出/分享 | 分享渲染后 HTML 或原文（调起系统分享） | P2 |
| F-12 | 自定义强调色 | 主题强调色可选（3–5 色） | P2 |
| F-13 | 字体选择 | 系统默认 / 衬线 / 等宽 三种阅读字体 | P2 |
| F-14 | 进入编辑 | 阅读页进入编辑；只读 URI 引导重新授权或另存为 | P0 |
| F-15 | Markdown 源码编辑 | 等宽源码编辑、选区、IME、主题联动 | P0 |
| F-16 | 格式工具栏 | 粗体、斜体、标题、引用、列表、行内/围栏代码、链接、分割线 | P0 |
| F-17 | 保存 / 另存为 | 覆盖保存原文件；SAF 另存为；失败保留草稿 | P0 |
| F-18 | 新建 Markdown | 首页新建；先编辑、首次保存时选择位置 | P0 |
| F-19 | 同页预览 | 编辑页内切换编辑/预览，复用现有原生渲染管线 | P0 |
| F-20 | 离开保护 | 未保存修改返回时保存/放弃/取消 | P0 |
| F-21 | 编码与换行保持 | 保持 UTF-8/BOM/UTF-16/GB18030 与 LF/CRLF；不可表示时另存为 | P0 |
| F-22 | 草稿兜底 | 编辑草稿仅存应用私有目录，成功保存后清理 | P0 |

### 4.2 明确不做（防范围蔓延）

- ❌ 富文本 / WYSIWYG / 隐藏 Markdown 语法的伪渲染编辑
- ❌ 云同步 / 账号 / 登录 / 多端协作 / 版本历史
- ❌ 多文件管理、文件树、多标签、插件系统
- ❌ 在线图床、网络图片加载（网络权限不存在，天然不支持）
- ❌ 插件系统、主题商店
- ❌ 广告、内购（v1 保持完全免费纯净，商业模式另行评估）

## 5. 信息架构与核心页面流程

### 5.1 信息架构（IA）

```
墨阅
├── 首页（最近文件列表）
│     ├── 空状态引导页（首次启动）
│     ├── 打开文件（系统文件选择器）
│     ├── 新建 Markdown*（v1.1）
│     └── 设置入口
├── 阅读页（核心页面）
│     ├── 正文渲染区
│     ├── 大纲抽屉（右侧滑出）
│     ├── 底部工具条（大纲 / 主题 / 字号 / 搜索*）
│     ├── 顶栏「编辑」*（v1.1）
│     └── 文内搜索栏*（P1）
├── 编辑页*（v1.1）
│     ├── 源码编辑区（EditText）
│     ├── 编辑/预览切换
│     ├── 格式工具栏
│     └── 保存 / 另存为 / 新建
└── 设置页
      ├── 主题模式（日间 / 夜间 / 跟随系统）
      ├── 字号 / 行距
      ├── 代码高亮主题（随明暗联动）
      ├── 清除最近记录
      └── 关于（版本 / 开源许可 / 隐私承诺说明）
（* 标注为 P1 功能对应的入口）
```

### 5.2 核心页面流程

**流程 1：打开文档（主闭环）**

```
启动 App → 首页最近列表
   ├─ 点击最近文件 ──────────────┐
   └─ 点击「打开文件」→ SAF 选择器 → 选择 .md
                                  ↓
        读取 → 检测编码 → 解析 Markdown → 渲染
                                  ↓
        阅读页（恢复上次进度* / 从头开始）
```

**流程 2：外部唤起（分享/打开方式）**

```
第三方 App 选择「墨阅」打开 .md → 直接渲染进入阅读页
   → 返回时回到第三方 App（该文档自动加入最近列表）
```

**流程 3：大纲跳转**

```
阅读页 → 点击底部「大纲」→ 右侧抽屉滑出（H1-H6 缩进树）
   → 点击某章节 → 抽屉收起 → 正文滚动至锚点 → 标题短暂高亮（闪烁 1 次）
```

**流程 4：主题切换**

```
阅读页 → 点击底部「日/夜」图标 → 即时切换（200ms 过渡动画，无闪烁）
设置页 → 主题模式 → 选择「跟随系统」→ 监听系统深色模式变化自动切换
```

**流程 5：轻编辑（v1.1）**

```
阅读页 → 点「编辑」
   ├─ 已有写权限 → 直接进入编辑页
   ├─ 无写权限   → 重新授权 / 仅另存为 / 取消
   └─ 文件 >1MB  → 提示仅支持阅读
        ↓
编辑页（源码编辑 + 格式工具） ↔ 预览
        ↓
保存 / 另存为 / 新建 → 更新最近列表 → 阅读页自动重载
```

### 5.3 异常流程

| 异常 | 处理 |
| --- | --- |
| 文件编码无法识别 | 按 UTF-8 兜底渲染，顶部 Toast 提示「编码可能异常」 |
| 文件过大（>5 MB） | 提示「大文件加载较慢」进度条；分段渲染 |
| 非 md 扩展名但内容为文本 | 照常解析渲染 |
| 文件中本地图片缺失 | 显示占位符（不阻断阅读） |
| SAF 授权失效（文件被移动/删除） | 最近列表标记「文件不存在」，点击时提示并可移除记录 |
| 无写权限或 provider 不支持写入 | 编辑页提示只读，可重新授权或另存为新文件 |
| 编码无法可靠识别 | 禁止覆盖原文件，仅允许以 UTF-8 另存为 |
| 保存写入失败 | 编辑页不关闭，保留应用私有草稿，可重试或另存为 |

## 6. 界面交互与视觉设计规范

### 6.1 设计基调

- **纸感阅读**：阅读区模拟纸张质感，正文最大宽度居中，留白充足；
- **零干扰**：阅读页默认沉浸（隐藏状态栏可选），工具条自动隐藏/轻触唤出；
- **单手可达**：核心操作（大纲、主题）集中在底部工具条，拇指热区内。

### 6.2 排版规范

| 项 | 规范 |
| --- | --- |
| 正文字号 | 默认 17sp（5 档：14/15.5/17/19/21） |
| 正文行高 | 默认 1.7 倍（3 档：1.5/1.7/1.9） |
| 正文字体 | 系统默认无衬线；代码块等宽（JetBrains Mono / 系统等宽） |
| 页边距 | 左右 20dp，段落间距 12dp |
| 标题层级 | H1 24sp / H2 21sp / H3 19sp / H4 17sp 加粗，逐级递减 |
| 代码块 | 字号 14sp，圆角 8dp 卡片，横向滚动，行号可选 |
| 大纲抽屉 | 宽度 78% 屏宽，H1 不缩进、每级缩进 16dp，当前章节高亮 |

### 6.3 配色方案

**日间主题（纸白）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#FAFAF7` | 暖白纸感 |
| 卡片/代码块背景 | `#F1F0EB` | |
| 正文文字 | `#2B2B2B` | 非纯黑，降疲劳 |
| 次要文字 | `#6E6E6E` | |
| 强调色（链接/高亮） | `#3A6EA5` | 沉稳蓝 |
| 代码块文字 | `#383A42` | |
| 代码高亮基调 | One Light 系 | 关键字 `#A626A4`、字符串 `#50A14F`、注释 `#A0A1A7` |
| 分割线/边框 | `#E2E1DC` | |

**夜间主题（墨黑，非纯黑护眼）**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#16181D` | 深墨蓝灰 |
| 卡片/代码块背景 | `#1F2229` | |

### 6.4 交互细节

| 交互 | 规范 |
| --- | --- |
| 主题切换动画 | 200 ms 颜色渐变，禁止整页闪白 |
| 大纲跳转 | 平滑滚动（300 ms），目标标题背景高亮闪烁 1 次（800 ms） |
| 工具条 | 滚动向下自动隐藏、向上或轻触屏幕中央唤出 |
| 图片查看 | 点击本地图片全屏查看，支持双指缩放 |
| 链接点击 | 弹底部弹层显示 URL，提供「复制链接」（因无网络权限，不提供「打开浏览器」，改为引导文案「已复制，可在浏览器中打开」） |
| 返回手势 | 阅读页返回 → 回首页；大纲抽屉展开时返回 → 先收起抽屉 |

## 7. 性能与体积约束指标

### 7.1 硬性指标（验收标准）

| 指标 | 目标值 | 红线值 | 测量条件 |
| --- | --- | --- | --- |
| 安装包体积（APK） | ≤ **6 MB** | ≤ 8 MB | release 包，单一 ABI 分包后 |
| 冷启动时间 | ≤ **400 ms** | ≤ 500 ms | 中端机（骁龙 7 系级），点击图标到首页可交互 |
| 热启动时间 | ≤ 150 ms | ≤ 200 ms | |
| 空闲内存占用 | ≤ **60 MB** | ≤ 80 MB | 首页静置 1 分钟 |
| 阅读内存占用 | ≤ **120 MB** | ≤ 150 MB | 打开 1 MB md 文档滚动阅读 |
| 首次渲染耗时 | ≤ 300 ms | ≤ 500 ms | 500 KB 文档，从选中到首屏渲染完成 |
| 大文档滚动帧率 | ≥ 55 fps | ≥ 45 fps | 2 MB 文档快速滚动 |
| 权限申请数量 | **0** | 0（不可突破） | manifest 中 uses-permission 为空 |
| 一期可编辑文件大小 | ≤ **1 MB** | — | 原始字节；超过保持只读，真机基准后可调整 |
| 网络流量 | **0 字节** | 0（不可突破） | 抓包验证全生命周期 |

### 7.2 达成手段（技术约束，供开发参考）

- 渲染引擎自研轻量解析（或选用裁剪版解析库，禁用按需加载之外的一切依赖）；
- 高亮引擎内置静态语法表，不引入运行时下载；
- 无 Splash 广告页、无后台 Service、无推送组件；
- 资源全部内置矢量图（SVG/VectorDrawable），位图资源极少；
- 大文档分段解析 + RecyclerView/虚拟滚动，避免一次性构建全量视图树；
- 包体积控制：R8 混淆压缩、去除未用资源、ABI 分包（arm64-v8a 优先）。

## 10. 风险与开放问题

| 项 | 说明 | 应对 |
| --- | --- | --- |
| 自研解析器的边界 case | 嵌套列表/表格内代码块等易出错 | 建立 CommonMark 标准测试集（spec.txt 用例 ≥ 90% 通过） |
