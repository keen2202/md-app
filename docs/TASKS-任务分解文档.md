### T02 Markdown 解析引擎
- **状态**：completed ｜ **里程碑**：M1 ｜ **预估**：2 人天
- **依赖**：T01
- **对应规范**：SPEC §1.2、§3.2、§5 文件 #5–#8
- **任务描述**
  - 目标：实现容错的两阶段 Markdown 解析器，输出带块索引与文本偏移的 AST。
  - 输入：Markdown 原文 String；CommonMark spec.txt 测试集。
  - 输出：`MarkdownParser`（含 `parse()` 与 `parseChunk()` 分段 API）、AST 密封类、单测。
  - 完成标准：spec.txt 用例通过 ≥90%（未过项登记豁免清单）；畸形输入 fuzz ≥1000 例零崩溃零死循环；500KB 文档解析 ≤300ms（中端机）。
- **检查清单**
  - [x] 块级解析：H1–H6、段落、有序/无序嵌套列表、GFM 表格、引用、分割线、围栏代码块
  - [x] 行内解析：粗体、斜体、删除线、行内代码、链接、本地图片
  - [x] HTML 内联块按纯文本转义（不渲染，SPEC §1.2 既定取舍）
  - [x] 所有解析分支有 fallback；游标前进断言防死循环
  - [x] AST 节点携带 blockIndex 与原文偏移（供搜索/进度/大纲使用）
  - [x] `parseChunk()` 分段解析接口可用（T16 前置）
  - [x] CommonMark 通过率报告 ≥90%，豁免清单归档
  - [x] fuzz 测试 1000 例零崩溃
